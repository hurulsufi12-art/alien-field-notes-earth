# Alien Field Notes: The Two-Day Earth

One line (187 characters, limit 200): a tourist review of Earth by an alien visitor — one clean joke about the locals' thousand greetings, a verdict with a rating, punch at the end.

> Earth: the locals invented a thousand ways to say hello, then spent centuries arguing about which greeting is correct. Charming, loud, mildly damp. 4/5 stars — would visit again, briefly.

`main.py` (Python 3.13, stdlib only) writes that line to `/output/entry.txt`. Deterministic: the same text on every run.
